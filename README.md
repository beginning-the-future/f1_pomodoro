# J.A.R.V.I.S. F1 Study Control 🏎️

A futuristic, F1-inspired study timer that turns focus sessions into a simulated Grand Prix, complete with animated circuits, AI rivals, tyre strategy, pit stops, engineer voice updates, and focus audio.

## Features
- 24 selectable circuits and 22 driver choices
- Adjustable focus sessions from 10 to 180 minutes
- Simulated race positions, tyre wear, and pit-stop strategy
- Animated space-tunnel background and live race track
- Synthesized focus music, custom audio, and optional voice updates

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select your race settings and start the session.

## Publish with GitHub Pages
1. Ensure the main HTML file is named `index.html` and is in the repository root.
2. Open **Settings → Pages** in your GitHub repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Notes
- No build tools or backend are required.
- Google Fonts are loaded online; browser audio and speech support may vary.
- Custom audio is loaded from your device for the current browser session.
- This version does not save settings or study history between reloads.
